# claude-skill-leera

A skill that turns rough location briefs into precise prompts for cinematic image and video models using a 4-step method (Deconstruct, Diagnose, Develop, Deliver). Claude replies in your language, the final prompt is always in English.

## Install

Copy this folder into your skills directory, for example `~/.claude/skills/leera`.
